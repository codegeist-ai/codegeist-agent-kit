Repository model

  1. Source on main

    Edit root source paths on a topic branch. Do not implement in generated release content.

  2. Generated release

    task release-build copies only runtime paths after source review.

  3. Consumer .opencode

    Consumers mount the release branch and keep project-specific behavior in local overlays.
